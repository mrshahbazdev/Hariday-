# Hariday

Offline catering & tandoor order book — event bookings (date, guests, menu, per-head rate), advance/balance khata, printable booking slips & receipts, prep lists (menu items × guests), per-event cost sheets with margin, event calendar print, defaulters + WhatsApp reminders. Encrypted local database, PIN roles, opt-in LAN sharing. No account, no internet.

## Dev
npm install && npm run dev

## Build (Windows .appx)
npm run dist:win

Set `build.appx.identityName` / `publisher` from Partner Center before building for the Store.
